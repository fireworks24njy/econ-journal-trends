# econ-journal-trends

## 2020–2025 中英文经济学顶刊文献热词挖掘与研究领域分析

> 基于 Web of Science 与中国知网文献数据的跨语言文本挖掘、领域分类与趋势比较。

## 项目简介

本项目选取 2020–2025 年间英文经济学 Top 5 期刊与中文代表性期刊的学术文献，利用自然语言处理与统计分析方法，识别中英文经济学研究中的高频词汇、关键短语及领域结构，并比较不同研究领域的年度变化趋势。

项目主要包括以下内容：

- 中英文文献数据清洗与标准化；
- 基于对数似然比（LLR）的 2-gram 与 3-gram 短语挖掘；
- 基于 TF-IDF 与向量空间模型（VSM）的零样本领域分类；
- 中英文期刊领域构成、年度趋势与组间差异检验；
- 英文 Top 5 期刊的领域内热词集中度与稳健性分析。

完整研究设计、统计检验与结果讨论见 [Phase 3 - August 15th.pdf](<Phase 3 - August 15th.pdf>)。

## 数据概览

| 语种 | 数据来源              | 期刊范围                                                    | 有效文献数 |
| ---- | --------------------- | ----------------------------------------------------------- | ---------: |
| 英文 | Web of Science（WoS） | AER、JPE、QJE、*Econometrica*、*Review of Economic Studies* |  **2,499** |
| 中文 | 中国知网（CNKI）      | 《经济研究》《管理世界》《中国社会科学》（经济学相关文章）  |  **1,786** |

英文样本仅保留 `Article` 类型文献；中文样本进一步剔除了非学术文件及与经济学关联较弱的文章。

## 核心方法

1. **文本构建**：对标题与关键词进行结构加权，并与摘要合并形成分析文本。
2. **热词挖掘**：分别统计单词与复合短语，使用 LLR 筛选具有稳定共现关系的候选短语。
3. **领域分类**：将文献映射至十大经济学领域，并保留最终分类、原始分类与高置信分类三种口径。
4. **统计分析**：综合使用 Logit、Pearson 卡方检验、置换检验及多重检验校正，并通过不同分类与词频口径开展稳健性分析。

项目同时使用 Sentence-BERT 进行了英文样本的语义嵌入对照。考虑到可解释性、跨语言一致性及当前人工标签条件，最终以 **TF-IDF + VSM** 作为主分析方法。

## 主要发现

- 英文 Top 5 期刊的代表性热词包括 `equilibrium`、`risk`、`field experiment`、`moral hazard` 与 `labor supply`；中文期刊则突出“企业”“高质量发展”“数字经济”“地方政府”等表达。
- 2020–2025 年英文 Top 5 期刊的整体领域构成较为稳定；劳动经济学的上升迹象与公共财政的阶段性回升应视为探索性发现。
- 中文期刊的国际经济学领域呈现较明显的上升信号，但该结果较大程度上受到 2025 年高占比的推动。
- 中英文期刊的平均领域侧重存在显著差异：英文样本相对侧重微观经济学，中文样本中金融学、公共财政与产业组织占比较高；但两组的整体年度变化轨迹未发现显著差异。
- 英文样本中，劳动经济学相较发展经济学具有较稳定的热词集中度优势；微观经济学与宏观经济学的总体词项集中度则较为接近。
