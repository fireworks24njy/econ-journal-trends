# econ-journal-trends

2020-2025 中英文经济学顶刊文献热词挖掘与研究领域演变趋势分析

---

## 📌 项目简介

本项目基于 2020–2025 年间经济学英文 Top 5 期刊与中文三大顶级期刊的文献数据，利用**自然语言处理（NLP）与文本挖掘技术**，系统性地完成了以下工作：

1. 中英文文献数据清洗与过滤（剔除书评、非学术公告及非经济学文献）；
2. 领域热词与关键短语挖掘（基于 LLR 对数似然比提取复合短语）；
3. 十大经济学子领域的分类映射与时序演变趋势可视化。

## ⚙️ 核心方法

### 1. 短语挖掘：对数似然比（LLR）

采用 LLR 统计模型自动提取 2-gram 与 3-gram 专业候选短语（如 `field experiment`、`moral hazard`、`数字经济`、`全要素生产率`），避免孤立单字词丢失语义信息。

### 2. 领域分类：TF-IDF + 向量空间模型（VSM）

本项目**最终采用传统且可解释性强的零样本分类框架**：

- **文本构建**：采用结构加权策略，即 `Full_Text = (Title × 2) + (Keywords × 2) + Abstract`，强化标题与关键词的领域决定作用；
- **特征表示**：计算词频-逆文档频率（TF-IDF）权重，将文献与 10 大经济学领域关键词库映射至高维稀疏向量空间；
- **相似度判定**：通过**余弦相似度**计算文献与各领域的匹配程度，划入最高分所属类别。

### 3. 深度学习对比实验（附注）

项目同时尝试了基于 **Sentence-BERT (all-MiniLM-L6-v2)** 的稠密语义嵌入方法，并设计了自适应分块与最大池化策略。  
但实验表明：在经济学学术文本中，**专用术语高度集中，词袋模型（TF-IDF）的近义词泛化需求低**。黑箱模型因缺乏领域预训练语料，产生了大量"杂项"误判，**最终效果弱于 TF-IDF + VSM**，故本项目以 TF-IDF 方法为主结论。

## 📈 主要发现

| 语种 | 高频关键词/短语（Top 示例） | 主导研究领域 |
| :--- | :--- | :--- |
| **英文 Top 5** | `equilibrium`, `risk`, `field experiment`, `moral hazard`, `labor supply` | **微观经济学**与**劳动经济学**占主导；实证方法（田野实验）热度突出 |
| **中文顶刊** | `中国`, `企业`, `数字经济`, `一带一路`, `高质量发展` | **产业组织**与**金融学**占比最大；政策导向型词汇频率极高 |

- **趋势稳定性**：2020–2025 年间，中英文学术界各子领域整体比例保持稳定，劳动经济学在两类数据库中均呈缓慢上升态势；
- **短期波动**：中文"产业组织"在 2023 年达峰（可能与疫情后企业数字化转型研究激增有关）；英文"发展经济学"在 2024 年前后有小幅回升。
